Run without VS Code

  1. Install JDK 17+ and Apache Maven 3.9+.
  2. Extract the project ZIP.
  3. Double-click run_windows.bat.
  4. Select Chrome, Firefox or Edge.
  5. Review reports inside target/surefire-reports.
